Reproduce: use manifest.json upstreamBaseUrl + path, download each font over
HTTPS, and verify SHA-256 before accepting any replacement. From repo root:
  sha256sum -c web/font-fallbacks/SHA256SUMS
Do not regenerate URLs with the current Google Fonts CSS API or use latest:
the pinned engine requests specific versioned paths, not arbitrary full fonts.

sampleCodePoints in manifest.json was independently read from the actual
WOFF2 cmap with fontTools 4.67.0 + Brotli 1.2.0 in a temporary audit venv.
Sample: U+25BE, U+2192, U+2713, U+26A0, U+1F4AA, U+1F3CB, U+1F9D8,
U+1F525, U+1F600. It is a sample, not a full repertoire or a shaping test.
The Flutter tests bind the audited metadata to bytes with SHA-256; they do
not decompress WOFF2 or claim to validate emoji shaping in a VM widget test.
No audit dependency is added to the Flutter application or Docker toolchain.

Serving: web/flutter_bootstrap.js sets fontFallbackBaseUrl to the local
font-fallbacks/ directory relative to document.baseURI. The engine continues
to choose fallback fonts normally. Unknown scripts outside this bounded
mirror may still request absent local paths (404/retry); no errors are hidden
and no Unicode/emoji text is stripped. Broader Unicode needs more fonts.
Keep the license/provenance files with the mirror when distributing it.
