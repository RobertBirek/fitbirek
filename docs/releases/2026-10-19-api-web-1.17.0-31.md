## Funkcjonalność

- Trening → Moje szablony: własna nazwa, uporządkowane ćwiczenia, serie,
  powtórzenia/czas, przerwy i opcjonalny ciężar. Zapis nie tworzy wykonania.
- Jawny start osobnej sesji; kopia sesji do nowego lub potwierdzana aktualizacja
  istniejącego szablonu. Historia i snapshoty pozostają bez zmian.
- Postęp potwierdzonych serii celu; dodatkowe ćwiczenia repeat nie przesuwają
  kursora. Wznowienie zachowuje dodatkowe ćwiczenia i ich wykonanie.
- Zakończenie wymaga rzeczywistej serii. Puste cele można zapisać jako szablon
  lub odrzucić. Usuwanie tombstonuje sesję i jej serie atomowo z outboxem;
  niezależne historyczne PR pozostają, o czym informuje potwierdzenie.
- Mentor proponuje walidowany szablon z katalogowych ID, otwierany do edycji.
  Samo wejście nie wysyła płatnej wiadomości ani nie zapisuje treningu.
